# WordCracker

An HTML5 canvas word path game. Ported from an original Android app.

**Play / repo:** https://github.com/justbobonx/wordcracker  
**Author / X:** https://x.com/just_bob

Each level is a letter grid that is completely filled with hidden words.
You must find all the hidden words exactly.
Bonus is ticking down with time and hints taken.

Controls
 - Tap and drag to highlight words.
 - **hint** will give the first 2 or 3 letters of an unfound word, and lower bonus.
 - **clear** will remove all wrong guesses.
 - **give up** will reveal all unfound words, end the level, and charge a penatly
